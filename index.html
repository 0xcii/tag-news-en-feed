This past January, StarkWare’s SN Stack went live. Despite various layer-2 stacks already live and layer-3 games existing on those chains, the team behind Nums claim that their decision to build with Starknet’s technology is because it allows for more “computationally complex and more ambitious” applications, said Tarrence van As, the CEO of Cartridge, the main developer firm behind Nums, in an interview with CoinDesk. Starknet, which uses Cairo as its programming language, is “much easier to express these types of applications,” van As added. (Ethereum uses Solidity, a different type of programming language, to build its applications. Most layer-2s use Solidity as well.)
