Lightspark, led by former PayPal executive David Marcus, provides backend infrastructure for connecting to what it calls the “Money Grid” — a decentralized network for real-time global payments. The integration puts London-based Revolut among the growing number of fintech firms leaning into faster, crypto-native payment systems.
